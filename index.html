RULES OF THE HOUSE

玩法说明

牌型

  • 单张 / 对子 / 三张 — 相同点数的 1、2、3 张。
  • 三带一 / 三带二 — 三张 + 一张单牌或一对。
  • 顺子 — 5 张以上连续单牌（3 至 A，不含 2 与王）。
  • 连对 — 3 对以上连续对子（3 至 A）。
  • 飞机 — 2 组以上连续三张，可带同数量的单牌或对子。
  • 四带二 / 四带两对 — 四张相同 + 两张单牌或两对。
  • 炸弹 / 王炸 — 四张相同 / 双王，可压任意牌型。
  • 花牌（万能牌） — 每局随机发给一位玩家（名字旁会亮起「花」标记），可代替 3 至 2 的任意点数（不能当王），参与所有牌型。

大小

3 < 4 < … < K < A < 2 < 小王 < 大王。同牌型同张数比点数，炸弹压一切，王炸最大。含花牌的组合按替代后的点数比较。

流程

依次叫地主或不叫。首位叫地主者进入抢地主环节，其余两位可依次抢地主——每抢一次倍数翻倍，最后抢到的人成为地主并拿走三张底牌。地主先出牌，率先出完手牌的一方获胜。无人叫地主则重新发牌。

计分

底分固定为 3，得分 = 底分 × 倍数。抢地主、炸弹、王炸均令倍数翻倍；春天（农民未出过牌）或反春天再翻倍。
